# Problem Framing and Analytical Review

صياغة المشكلات التحليلية ومراجعة التحليلات

Data Science Track · SDAIA Academy · DS-310 · Level 300

REPLACE: one line under the title: what participants can do after the course

Participants practise the work before and after an analysis, using requests from Ghadeer Water Company, a fictional water utility. They turn vague requests into decision questions with an estimand, a metric and a decision rule, interview a role-played manager, use domain knowledge of metering, billing and repair to see where the data mislead, and test whether data and deadline make the question answerable. They then review analyses by peers and by an assistant and write review notes ranked by consequence. Metric definition is DS-307; team review standards are DS-407.

**Format:** Intensive: 3 teaching days of four sessions and a capstone day, with guided pre-work and a tracked follow-up task

**Course page:** https://sdaiaacademy.github.io/ds-310/

## Outcomes

| | Outcomes | Level | Evidence |
|---|---|---|---|
| LO1 | Prepare a decision question with estimand, population, metric and decision rule from a vague request, given five requests from the utility's managers | Applied | framing cards a peer can plan from without further questions |
| LO2 | Analyse a metric set for proxy failure and gaming, and propose guardrail metrics, given the utility's metric tree for water loss and customer service | Applied | an annotated tree with two guardrails and the behaviour each prevents |
| LO3 | Use domain documents and an expert interview to map how the data behind a metric are produced, given a briefing pack on metering, billing cycles and leak repair, and a role-played engineer | Applied | a process map marking three points where the data can mislead |
| LO4 | Design an analysis plan stating data, method, threats to validity and the result that would change the decision, given a framed question, a data inventory and a two-week deadline | Performance | a two-page plan scored against a rubric |
| LO5 | Review an analysis for errors in question fit, data handling, method, inference and communication, given three seeded-flaw notebooks, one generated by an assistant | Performance | review notes ranking the critical flaws by consequence, each with a fix |
| LO6 | Decide whether a request needs description, an experiment, a causal analysis, a predictive model or no analysis, given a role-played sponsor whose constraints change during the meeting | Performance | a recommendation defended against the assessor's challenge |
